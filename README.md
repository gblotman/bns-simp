# Bagels & Stuff, simple version

Static landing page for Bagels & Stuff (Kfar Saba). Plain HTML, CSS and JS with no build step.

- `index.html`: home page
- `visit.html`: how to get there
- `accessibility.html`: accessibility statement
- `css/`, `js/`, `images/`: assets

## Run locally

    npx serve .

Then open http://localhost:3000.

## Publish

Upload the contents of this folder (with `index.html` at the root) to any static hosting service.

To change the gallery, replace the files `images/gallery-*.jpg` or edit the gallery section in `index.html`.
